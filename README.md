Página estática Reader Books com três cartões (hábitos de leitura, lógica de programação e linguagens). As setas em `scripts.js` trocam a classe `active`. Fonte Montserrat/Titillium e ícones Remix Icon vêm de CDN.

## Stack

- HTML5, CSS3 e JavaScript, sem build

## Estrutura

```
index.html
styles.css
scripts.js
```

O HTML pede `./img/hábitos.png`, `./img/lógica.png` e `./img/linguagens.png`. Essa pasta não está no repositório.

## Como rodar

```bash
git clone https://github.com/gabrielteramae/fundamentos-web.git
cd fundamentos-web
```

Abra `index.html` no navegador. Sem os arquivos de `img/`, as figuras dos cartões não aparecem.
